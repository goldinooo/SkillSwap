## Description

**Skill Swap** is a web platform where people exchange knowledge instead of money. Users list the skills they can teach and the skills they want to learn, and the platform matches them with a compatible partner: someone who knows what they want to learn and wants to learn what they know.

Once matched, partners chat in real time, complete a learning session, and rate each other. Every completed session earns XP, badges, and reputation, and users climb a leaderboard as they teach and learn more.

**Goal:** make peer-to-peer learning simple, social, and rewarding, so that everyone is both a teacher and a student.

**Key features:**
- Secure authentication (email/password, Google and 42 intra OAuth, 2FA)
- User profiles with "I teach" and "I want to learn" skill lists
- Matching based on skill compatibility, with advanced search (filters, sorting, pagination)
- Real-time chat, friends system, and online status
- Session flow with mutual ratings
- Gamification: XP, levels, streaks, badges, and a leaderboard
- Real-time notifications
